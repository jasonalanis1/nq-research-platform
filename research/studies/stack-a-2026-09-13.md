# Stack A — the first conditional stack, and its result

September 13th, ~9:12 pm CT · scan_035_2026-09-13 · hyp-000161 · spec hash `4df7b408`
Format: conditional stack (adopted ~9:00 pm CT the same evening). Attempt 1 of 2.

## The question

Does the B2 Risk/State Engine's expected-range regime — known at the prior close — change
what a B3 opening-range breakout *means*? This is the bot's own BASE vs BASE+B2 question,
asked as one pre-registered hypothesis instead of by accumulation.

## The design, as frozen before the run

Two layers: context = combined expected-range multiplier, top tercile (edges fixed on
Discovery); trigger = the frozen B3 break (first close beyond the 09:30–10:00 range,
10:00–11:30 ET, entry at the next bar's open, stop at the opposite side, target 1.0×
range width, time exit 15:55, one trade per session). Outcome: realised R. Paired, so the
gating number is a difference between two **disjoint** cells of the same trigger —
in-context versus out-of-context — not the subset-versus-whole comparison that produced
the construction drift the blind Gate caught on hyp-156.

Floor: 100 occurrences per cell, with the minimum detectable effect written down first
(≈0.14R standard error at n=100, so ≈0.23R resolvable before multiplicity). Spec hashed
into STACK_REGISTRY before the runner was allowed to execute. Look-cells examined
beforehand: zero — the interaction-mining mode does not exist yet.

## The result

| cell | n | mean R |
|---|---|---|
| in context (top-tercile expected range) | 566 | −0.0109 |
| out of context | 977 | −0.0357 |
| unconditional reference (not evidence) | 1,543 | −0.0266 |

Gating difference (in − out): **+0.0247R**, bootstrap 90% CI **(−0.0496, +0.0976)**,
Šidák-adjusted at the project's Discovery trial count N=460: **(−0.1401, +0.1896)**.

**Verdict: powered null.** The interval crosses zero before any correction. With 566 and
977 occurrences the design excludes any difference larger than about +0.19R — comfortably
smaller than the effect the mechanism implied — so this is a real answer, not a shrug.
The sign is the predicted one, and a sign alone is not a result.

## What this actually tells us

The expected-range regime is a **sizing and permission** input, which is exactly what its
underlying validated facts (prior-day range, VXN versus trailing realised) support. It is
not an entry filter. Nothing in the paper run should treat B2 as changing the entry's edge,
and the BASE vs BASE+B2 comparison there now has a stated prior: expect a difference in the
*distribution* of outcomes from sizing, not in the entry's expectancy.

The unconditional B3 figure in the table is a placeholder's arithmetic, not a finding. The
placeholder exists to make the order path real; its P&L is never evidence.

## What it cost, and what it leaves

Two trials (the paired family), one attempt of the two this family gets, and one of the two
powered nulls that would close the conditional-stack format entirely. The format itself is
not in question yet: one honest null on its first outing is the format working, not failing.
The 2-layer ceiling lifts to 3 now that a result exists.

Retest is closed on any variant of this pairing — different tercile edges, different breakout
windows, different targets are the same question. A different, non-volatility context variable
with its own mechanism would be a new stack.
