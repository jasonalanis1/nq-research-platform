# raw/

The dump zone. Paste ideas, articles, half-formed thoughts, or "I noticed
X happen at the open" observations here — nothing needs to be polished,
correct, or even complete. This is a scratch pad, not a conclusion.

Suggested format: one file per idea/session, named by date, e.g.
`2026-08-16-noticed-fakeout-before-news.md`. Doesn't need to follow a
strict template — plain notes are fine. If something here turns out to
be testable, it graduates into a proper hypothesis file in
`../experiments/` with a row in `../experiments/_index.md`.

Nothing here yet — this fills up as ideas come in.
