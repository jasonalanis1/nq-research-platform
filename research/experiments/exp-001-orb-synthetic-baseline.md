# exp-001 — ORB synthetic-data baseline

**Date:** 2026-08-15
**Status:** retest (pipeline validation run, not a real edge test)

## Hypothesis

An Opening Range Breakout — range defined by the high/low of the first 15
minutes after the 8:30 AM NY open, breakout watched for over the
following 60 minutes, stop at the opposite side of the range, target at
1x the range width — has a tradeable edge on NQ.

## Why this was run

Jason hadn't described his actual setup yet, so this well-known, standard
pattern was used as a default/placeholder to build and prove out the full
pipeline (detect → backtest → score) before a real setup was available.

## Data used

`data/NQ_1min_SYNTHETIC.csv` — 90 fake trading days generated by
`src/generate_sample_data.py` (a random walk with a volatility bump after
the open). **Not real market data.** This cloud sandbox can't reach real
data providers; synthetic data was the only option available for this
session.

## Method

`src/detect_setups.py` → `src/backtest.py` → `src/score_results.py`,
default parameters (`RANGE_MINUTES=15`, `BREAKOUT_WINDOW_MINUTES=60`,
target = 1x range width).

## Results

- 90 days scanned, 77 signals detected (38 long, 39 short), 13 days with
  no breakout.
- Of 77 signals, 46 resolved (hit stop or target) before the synthetic
  data ran out for the day; 31 were unresolved (synthetic data only
  covers 6:00-11:00 AM, so some trades simply ran out of bars).
- Of the 46 resolved: 37.0% win rate, average win +0.93R, average loss
  -1.00R, expectancy -0.287R per trade, profit factor 0.51, max drawdown
  -15.10R.
- Full trade-by-trade log: `data/backtest_results.csv` (as of this run —
  note this file gets overwritten by re-runs, unlike this experiment
  record).
- Equity curve: `charts/equity_curve.png` (steady decline, consistent
  with negative expectancy — see journal entry for why that's actually a
  good sign here).

## Interpretation

This result says nothing about whether ORB has a real edge on NQ. It
confirms the *pipeline* is behaving correctly: fed pure random-walk data
with no real structure, it correctly found no edge rather than
manufacturing a fake one. That's the bar a backtest engine needs to clear
before its results on REAL data can be trusted.
