## Result and why it matters
One promising-looking idea was investigated in real depth and then
correctly stopped before any real cost was sunk into it: four times a
year, a large batch of index options and futures all expire on the same
Friday ("quad witching"), and everyone holding an expiring contract has
to close it out or roll it forward right around the closing bell,
producing a real, well-documented rush of forced trading. That's
exactly the kind of clean, non-discretionary mechanism this project
looks for. But before writing it up, a check of the actual data turned
up a known problem, already discovered once before in an earlier
entry: the price history file this project uses has a technical gap
specifically on those witching Fridays -- essentially zero usable
price bars for the trading session, because of how the underlying data
provider stitches together back-to-back futures contracts. Two spot
checks against real witching dates confirmed the gap is still there.
In plain terms: this project can't currently see what actually happens
on the very days it would need to study. Rather than force a test on
broken data, the candidate was set aside, with the reason written down
so it isn't investigated again from scratch by mistake -- it would need
a different underlying data file (a "roll-adjusted" price series) to
ever be testable, not a workaround within the current one.
No other new candidate was found across the map, literature, or
