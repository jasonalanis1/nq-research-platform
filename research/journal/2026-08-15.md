# 2026-08-15 — Project kickoff

**Who:** Jason + Claude, first session.

**What we did:**
- Scaffolded the whole project: `src/`, `data/`, `charts/`, `docs/`,
  under git version control.
- Discovered this cloud sandbox can't reach any real market data site
  (Yahoo Finance, Databento, etc. all blocked by the network allowlist).
  Built `src/generate_sample_data.py` as a clearly-labeled synthetic-data
  fallback so we could keep building without being stuck.
- Built the full pipeline, Stage 0 through Stage 4:
  - `data_fetch.py` — pulls real NQ minute data (ready for Jason's Mac).
  - `detect_setups.py` — flags Opening Range Breakout signals. Built as a
    **placeholder** since Jason hadn't described his real setup yet.
  - `backtest.py` — simulates each signal forward to see if it hit its
    stop or target first.
  - `score_results.py` — turns trades into win rate, expectancy, profit
    factor, max drawdown, and an equity curve chart.
- Added an 8-test automated test suite (`tests/`) covering the core
  detection and backtest logic against known-answer examples.
- Set up GitHub backup instructions and Claude Code setup instructions in
  the README, for continuing on Jason's own Mac.
- Set up a daily scheduled check-in (push notification — email never
  worked, we troubleshot it at length and couldn't find the cause; push
  did work).
- Added this `research/` knowledge layer + a `CLAUDE.md` at the project
  root, per Jason's request, to keep future sessions organized: raw
  ideas, dated journal entries, a hypothesis-tracked experiments log, and
  refined setup definitions, with rules about never overwriting old
  experiment results or hand-editing pipeline output.

**What we learned:**
- The pipeline works correctly: run against synthetic (random-walk) data,
  the placeholder ORB setup came back with a 37% win rate and -0.29R
  expectancy — a clean LOSS, which is the *correct* result for a random
  dataset. See `experiments/exp-001-orb-synthetic-baseline.md`.
