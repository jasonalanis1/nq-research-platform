# journal/

One dated entry per work session, in plain language — what we did, what
we decided, and why. Filename format: `YYYY-MM-DD.md` (if there's more
than one session in a day, `YYYY-MM-DD-2.md`, etc.).

This is meant to read like a diary, not a formal report: short, honest,
easy to skim when picking the project back up after time away.
